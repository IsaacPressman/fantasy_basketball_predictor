# Fantasy Basketball ML Projections

Machine learning pipeline for predicting NBA player fantasy basketball performance.

## Features
- Historical NBA data collection (2019-2024)
- Feature engineering for player projections
- XGBoost/LightGBM models for stat predictions
- Confidence intervals and uncertainty quantification

## Setup

### Prerequisites
- Python 3.12
- pip

### Installation
```bash
# Clone repository
git clone https://github.com/YOUR_USERNAME/fantasy-basketball-ml.git
cd fantasy-basketball-ml

# Create virtual environment
python3.12 -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows

# Install dependencies
pip install -r requirements.txt
```
